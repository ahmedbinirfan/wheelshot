# Wheelshot

Menu-bar app for macOS. Click the scroll wheel and macOS starts a region screenshot (Control-Shift-Command-4). Other mouse buttons are left alone.

Requires an Apple silicon Mac on macOS 13 or later, plus Accessibility permission. The app does not appear in the Dock.

## Build

```bash
./build.sh
```

That compiles `main.swift` and installs `~/Applications/Wheelshot.app`.
